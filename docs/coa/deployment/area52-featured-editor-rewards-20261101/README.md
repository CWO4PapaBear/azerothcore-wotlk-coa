# Featured Draft editor and milestone rewards

Preparation only. Nothing in this task is authorized for activation, installation, a realm restart or publication. Final activation readiness is recorded separately in `ready.json` after package integrity and the stable PowerShell CheckOnly pass.

The editor uses the existing Build Architect, Wardrobe and Vanity modules. GM-only Featured fields include a character model, nine armor slots, main hand, off hand/shield, ranged, ground/flying mounts, a full-armor-set picker and a separate AI Bot Rotation text section immediately after Rotation. Selection does not redeem, buy, equip or grant ownership. Full sets replace armor only. Relics are excluded. Two-handed/offhand conflicts and invalid mount categories are rejected. Existing named archetype selection and the terminal character-creation reference are preserved.

GM selections are saved in the build's existing description using a versioned fourteen-item section. AI Bot Rotation is a distinct escaped text section; it is retained by the build serialization/copy/library path. It is not executable code and this package does not install a bot rotation interpreter. GMs must assign the desired rewards and save the Featured Draft. Empty slots grant nothing, including mounts; this package does not invent missing assignments. Rewards follow the character's selected build revision, as the existing Draft lifecycle does.

Milestones: shoulders10, chest13, gloves16, ground mount20, all assigned weapons22, head25, boots28, bracers36, belt40, back45, legs50, flying mount60. New `area52_featured_milestones` claims are unique by character and level. Claim, item persistence, mail and attachment rows commit together using the asynchronous database worker. Online mailbox state changes only after successful commit. Reconnects and duplicate/concurrent delivery requests cannot issue the milestone again. Bots and forfeited/non-Draft characters are excluded. Already mailed items remain after abandoning a Draft. Maximum-level Mystic Enchant rewards remain a separate existing mechanism.

Combined pending corrections are preserved: `draft-reentry-warning-20261101` (under10 Draft re-entry plus advancement confirmation) and `cryotherapist-preview-20261101` (Cryotherapist Frostfire Remembrance Blue; Cryomancer restored Frostbitten Staff). ## GM workflow after owner activation

Edit or copy a build, select DRAFT BUILD (Featured), and choose its character-creation archetype from the existing name dropdown. Below Rotation, enter optional AI Bot Rotation text and configure Featured Vanity rewards. Select an armor/weapon slot to open Wardrobe, or use the full-set button to replace armor slots together. Select a ground/flying mount slot to open the Vanity mount picker. Choosing an eligible entry returns to the editor and updates the preview; Cancel leaves assignments unchanged. Clear a slot to omit that reward. Save the build to persist the assignments. This editor workflow does not grant items to the GM.

For live tester acceptance after activation, review preview placement and picker navigation, save/reopen the Featured build, and check reward delivery at the listed milestones. Engineering checks below do not claim graphical/gameplay certification. No live testing is required to complete this preparation.
