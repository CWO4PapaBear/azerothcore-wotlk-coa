## Prices and XP

Alpha pricing requested by the owner: every individual heirloom costs 500 Runes of Ascension (item 375250, new cost ID 900053). Each nine-piece cache costs 3600 (new cost ID 900052), retaining the 20% discount from the 4500 individual total. Prices may be retuned after Alpha. These private cost rows leave shared upstream cost tiers unchanged. The primary client's ItemAddon.dbc names item 375250 Rune of Ascension; the earlier Descension label in these notes was incorrect. No XP effects are changed.

Only chest and shoulders among these nine-piece sets currently carry XP spell 57353. The other seven pieces have no XP spell or XP set bonus. This change does not silently add XP bonuses or change item scaling. The Might cloak's separate spell 540336 is preserved.

## Installation

Apply this pending migration only to the Area 52 world database. Enable `Area52.GuardianHeirlooms.Enable = 1` in its server configuration. The menu routing additionally requires Hero/live settings and a Hero with no non-Free-Pick mode bits; the default is disabled for other setups. The SQL removes list 900011, so do not install it on another game-mode database.

Run `python tools/area52_heirloom_cost.py INPUT_ItemExtendedCost.dbc OUTPUT_ItemExtendedCost.dbc` against matching effective client/server tables, then package the output as `DBFilesClient/ItemExtendedCost.dbc` in the managed Area 52 client overlay and install the identical server DBC. The generator preserves all existing rows and rejects a conflicting cost ID. Do not replace a mixed client archive with the standalone cost-only staging archive; merge the member through the existing Area 52 release process. Restart only Area 52 after backups. Pair the client and server price-table update before gameplay testing; a source push does not distribute that data.
